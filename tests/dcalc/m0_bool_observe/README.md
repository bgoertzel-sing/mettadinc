# m0_bool_observe: (To Bool) maps as Observe ports in Crisp M0 (t-2026-11-23-mettadinc-m0-bool-observe)

Gap (a) of t-2026-11-20-mettadinc-m0-subset-reach (repro `tests/dcalc/examples_e2e/repro/m0_blocker_a_bool_observe.metta`).

## What is lowered, and why it means what the spec says

`(Machine M (States C) (Observe label f) ...)` with `(Map f (From C) (To Bool) (Cases ...)|(Table ...))`, in a module with
`(Profile Crisp)`, where C is a declared carrier (or the parent of a Subset/Reach state carrier, restricted as usual).

- Registry `libraries.Core`: `Bool` is a builtin type; `True` and `False` are Core constants.
- Spec Def 3.1/3.2 (`mettadinc_language_spec.txt` l.676-700): each query label j has a value type Y_j with crisp
  equality unless a tolerance is declared, and o_j : X -> Y_j is total. So the port is the query f into
  Y = Bool = {False, True} compared by literal equality: the same machine as one that observes into an Enum
  carrier with two elements.
- Spec 5.4 (l.1851-1857): every input matches exactly one case, outputs stay in the declared type. A case value that
  is not True/False, a missing case or overlapping cases are InvalidInput.

Implementation (`src/dcalc/model.c`, `admit_bool_observe_map`, `bool_carrier`): a Map whose To is `Bool` is still
skipped at its declaration (as before). When an Observe port of a Crisp machine names it, it is admitted on demand
against one implicit carrier Bool = (False True), shared by every Bool map of the module, so values compare
across machines too (CheckAbstractionMap compares the observation carriers of source and target). This carrier
is never found by name, so no Carrier, Product, Tolerance or other declaration can refer to Bool through it.

Still outside the fragment (Unsupported, the reason names the form):
- a Representation whose Encode map targets Bool: "Encode map f targets Bool; a (To Bool) map is lowered only as an Observe port";
- a Bool Observe map in a non-Crisp module (Graded, ...): "... a (To Bool) Observe map is lowered only in a Crisp module";
- a Bool Observe map that hits another blocker (If/Eq/And/Or/Not in Cases, type-form From): the reason quotes it,
  e.g. "Machine M: Observe live: Map live: Cases row 0 uses an operator outside the M0 fragment".
A Bool map used only as an Action, a Subset predicate or elsewhere behaves exactly as before.
